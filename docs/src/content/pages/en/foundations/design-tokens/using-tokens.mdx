# Using design tokens

GC Design System components already use design tokens, so you do not need to apply tokens yourself when using our components.

## Decide if you need tokens

### In code

Start with <gcds-link href={links.en.shortcuts}>CSS Shortcuts</gcds-link>. Use design tokens directly in your CSS only when no CSS Shortcuts class covers the style you need.

### In Figma

Use design tokens when you need to create custom styles outside GC Design System components.

## Choose a design token

Choose the right token type:

- **Use global tokens** that match the styles you need. When a global token is semantic, choose it based on its stated purpose. See <gcds-link href={links.en.tokenNaming}>token naming</gcds-link> to understand what a token’s name tells you.
- **Use base tokens** when there are no global tokens that meet your styling need. Base tokens exist only for colour, providing you a larger palette of choices.
- **Avoid using component tokens**, since they’re tied to GC Design System components. Using them outside their associated component can cause unexpected changes when we update the component.

Explore our foundations to choose the right token for your needs.

## Apply design tokens

### In code

Design tokens are available as CSS custom properties in our <gcds-link href={links.en.githubTokens} external>token repo</gcds-link>.

In your CSS file, use `var()` to reference the token as the value of the property you’re styling, as in:

```CSS
font: var(--gcds-font-text);
color: var(--gcds-text-primary);
background-color: var(--gcds-bg-white);
```

### In Figma

Design tokens are available as Figma variables in our <gcds-link href={links.en.figmaTokens} external>token library</gcds-link>.

Import the token library (“GCDS Token library”) into your file. Then, in Figma’s Design panel, choose a variable or style from the library for the property you want to change. For example, choose a colour under **Fill** or a text style under **Typography**.
