# Overflow

The overflow class sets the `overflow` property. It controls how content is handled when it does not fit in its container and overflows.

<ShortcutsTable shortcuts={shortcuts} />

## Examples

### Visible<br />`overflow-visible`

<CodePreview demoClass="bg-light b-md b-default mb-600 p-150 limited-size">
  <div class="overflow-visible">
    Content that doesn't fit in this element overflows horizontally and
    vertically.
  </div>
</CodePreview>

### Visible horizontal (x)<br />`overflow-x-visible`

<CodePreview demoClass="bg-light b-md b-default p-150">
  <div class="overflow-x-visible" style="width: 250px;">
    <p style="width: 500px;">
      Content that doesn't fit in this element overflows horizontally.
    </p>
  </div>
</CodePreview>

### Visible vertical (y)<br />`overflow-y-visible`

<CodePreview demoClass="bg-light b-md b-default mb-300 p-150 limited-size">
  <div class="overflow-y-visible">
    Content that doesn't fit in this element overflows vertically.
  </div>
</CodePreview>

### Hidden<br />`overflow-hidden`

<CodePreview demoClass="bg-light b-md b-default p-150 limited-size">
  <p class="overflow-hidden">
    Content that doesn't fit in this element is invisible, but still exists for
    screenreaders.
  </p>
</CodePreview>

### Hidden horizontal (x)<br />`overflow-x-hidden`

<CodePreview demoClass="bg-light b-md b-default p-150">
  <div class="overflow-x-hidden" style="width: 250px;">
    <p style="width: 500px;">
      Content that doesn't fit to the left and right of this element is
      invisible, but still exists for screenreaders.
    </p>
  </div>
</CodePreview>

### Hidden vertical (y)<br />`overflow-y-hidden`

<CodePreview demoClass="bg-light b-md b-default p-150 limited-size">

</CodePreview>
