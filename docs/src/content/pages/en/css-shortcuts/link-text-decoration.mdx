# Link text decoration

The link text decoration class sets the `text-decoration` property. It adds or removes an underline to a link.

<ShortcutsTable shortcuts={shortcuts} />

## Examples

### Underline<br />`link-underline`

<CodePreview>
  <a href="#" class="link-underline">
    This link is underlined.
  </a>
</CodePreview>

### No underline<br />`link-no-underline`

<CodePreview>
  <a href="#" class="link-no-underline">
    This link is not underlined.
  </a>
</CodePreview>
