# Text transform

The text transform class sets the `text-transform` property. It controls the capitalization patterns of text.

<ShortcutsTable shortcuts={shortcuts} />

## Examples

### Capitalize<br />`text-capitalize`

<CodePreview>
  <p class="text-capitalize">
    This text has the first letter of each word capitalized.
  </p>
</CodePreview>

### Lowercase<br />`text-lowercase`

<CodePreview>
  <p class="text-lowercase"> This text has all characters in lowercase. </p>
</CodePreview>

### Uppercase<br />`text-uppercase`

<CodePreview>
  <p class="text-uppercase"> This text has all characters in uppercase. </p>
</CodePreview>

### None<br />`text-none`

<CodePreview>
  <p class="text-none">
    This text is displayed as originally entered. Any text transformations are
    removed.
  </p>
</CodePreview>
