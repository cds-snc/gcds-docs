# Line height

The line height class sets the `line-height` property. It controls the vertical spacing between lines of text.

<Notice
  title="Use with caution"
  html={`In most cases you do not need to use this class. Body text and heading elements are <gcds-link href="/en/styles/typography">styled to match GCDS by default</gcds-link>. Use semantic HTML tags , like <code>h1</code>, <code>h2</code> whenever possible.`}
/>
