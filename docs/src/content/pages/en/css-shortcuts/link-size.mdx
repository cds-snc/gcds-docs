# Link size

The link size class sets the `font` property. It controls how big or small a link is.

<Notice
  title="Use with caution"
  html={`In most cases you do not need to use this class. Links are <gcds-link href="/en/components/link">styled to match GCDS by default</gcds-link>. Use the semantic HTML tag <code>a</code> or the GCDS component <code>gcds-link</code> whenever possible.`}
/>
