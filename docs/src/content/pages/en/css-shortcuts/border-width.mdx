# Border width

The border width class sets the `border-width` property. It controls the width of an element's border.

<ShortcutsTable shortcuts={shortcuts} description={tableDescription} />

## Examples

### All side<br />`b-<value>`

<CodePreview demoClass="bg-light p-150">
  <p class="b-0"> This element has a border width of 0 on all sides.</p>
</CodePreview>

<CodePreview demoClass="bg-light p-150">
