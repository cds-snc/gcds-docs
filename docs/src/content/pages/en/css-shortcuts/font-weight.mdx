# Font weight

The font weight class sets the `font-weight` property. It controls how bold text is.

<Notice
  title="Use with caution"
  html={`<gcds-link href="/en/styles/typography#font-weights">View GCDS typography guidance</gcds-link> to choose the right font weight for your context.`}
/>

<ShortcutsTable shortcuts={shortcuts} />

## Examples

### Regular<br />`font-regular`

<CodePreview>
  <p class="font-regular"> This element uses the default font weight.</p>
</CodePreview>

### Light<br />`font-light`

<CodePreview>
  <p class="font-light"> This element uses a light font weight.</p>
</CodePreview>
