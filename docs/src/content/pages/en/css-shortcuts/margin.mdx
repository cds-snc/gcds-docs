# Margin

The margin class sets the `margin` property. It controls the space outside the border of an element.

<LogicalPropertiesNote />

<ShortcutsTable shortcuts={shortcuts} description={tableDescription} />

## Examples

### All sides<br />`m-<value>`

<CodePreview demoClass="container-full bg-primary text-light p-150">
  <p class="m-0">This element has no margin on all sides.</p>
</CodePreview>

### Top side<br />`mt-<value>`

<CodePreview demoClass="container-full bg-primary text-light p-150">
  <p class="mt-auto">
    This element lets the browser automatically calculate the margin on the top
    side.
  </p>
</CodePreview>

### Bottom side<br />`mb-<value>`

<CodePreview demoClass="container-full bg-primary text-light p-150 example-margin">
  <p class="mb-900">
    This element has a margin of --gcds-spacing-900 on the bottom side.
  </p>
</CodePreview>

### Left side<br />`ms-<value>`

<CodePreview demoClass="container-full bg-primary text-light p-150 example-margin">
  <p class="m-900 ms-0">This element has no margin on the left side.</p>
</CodePreview>

### Right side<br />`me-<value>`

<CodePreview demoClass="container-full bg-primary text-light p-150 example-margin">
  <p class="m-900 me-0">This element has no margin on the right side.</p>
</CodePreview>

### Horizontal sides<br />`mx-<value>`

<CodePreview demoClass="bg-primary text-light p-150 example-margin">
  <p class="container-md mx-auto">
