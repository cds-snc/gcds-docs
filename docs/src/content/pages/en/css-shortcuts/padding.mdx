# Padding

The padding sets the `padding` property. It controls the space inside an element between its content and border.

<LogicalPropertiesNote />

<ShortcutsTable shortcuts={shortcuts} description={tableDescription} />

## Examples

### All sides<br />`p-<value>`

<CodePreview demoClass="d-inline-block bg-primary text-light">
  <p class="p-0">This element has no padding on all sides.</p>
</CodePreview>

### Top side<br />`pt-<value>`

<CodePreview demoClass="d-inline-block bg-primary text-light">
  <p class="pt-300">
    This element has a padding of --gcds-spacing-300 on the top side.
  </p>
</CodePreview>

### Bottom side<br />`pb-<value>`

<CodePreview demoClass="d-inline-block bg-primary text-light">
  <p class="pb-300">

  </p>
</CodePreview>

### Left side<br />`ps-<value>`
