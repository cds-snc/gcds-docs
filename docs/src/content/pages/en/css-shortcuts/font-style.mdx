# Font style

The font style class sets the `font-style` property. It adds or removes italic styling of text.

<Notice
  title="Use with caution"
  html={`<gcds-link href="/en/styles/typography#italics">View GCDS typography guidance</gcds-link> to choose the right font style for your context.`}
/>

<ShortcutsTable shortcuts={shortcuts} />

## Examples

### Normal<br />`font-normal`

<CodePreview>
  <p class="font-normal">
    This element displays text without italic styling and is used in most cases.
  </p>
</CodePreview>

### Italic<br />`font-italic`

<CodePreview>
  <p class="font-italic">
    This element displays text with italic styling. It's used sparingly for
    short text strings to limit cognitive load.
  </p>
</CodePreview>
