# Espacement

L’espacement aide à positionner les éléments à l’écran et dans les composants.

## Sur cette page

## Système d’espacement

Système de design GC utilise un système d’espacement cohérent basé sur le rythme vertical et une taille de base.

Le rythme vertical consiste à aligner le texte sur des lignes horizontales espacées de manière égale, selon un motif répétitif. Cet espacement vertical régulier facilite le survol, la lecture et la compréhension du contenu.

Les valeurs d’espacement sont définies en rem. Elles sont toutes calculées à partir d’une taille de base de `1,25 rem` (`20 px`).

Le système d’espacement est représenté par des <gcds-link href={`${links.fr.designTokens}#unites-de-style-globales`}>unités de style globales</gcds-link>.

## Utiliser l’espacement

### Espacez selon les relations entre les éléments

- Utilisez de petites valeurs d’espacement pour regrouper les éléments de contenu liés.
- Utilisez de grandes valeurs d’espacement pour séparer les groupes d’éléments.
- Dans la mesure du possible, alignez les objets à la verticale et à l’horizontale.

### Choisissez comment appliquer l’espacement

Limitez-vous aux valeurs de l’échelle d’espacement de Système de design GC pour maintenir la cohérence.

- Utilisez le <gcds-link href={links.fr.grid}>composant grille</gcds-link> pour organiser les éléments et contrôler l’espacement entre eux. Ses attributs `gap` acceptent des valeurs de `150` à `800`, qui correspondent aux unités de style d’espacement de Système de design GC.
- Utilisez les raccourcis CSS pour appliquer des marges et des espacements intérieurs. Les raccourcis CSS utilisent les unités de style d’espacement de Système de design GC.
- Si aucun raccourci CSS ne répond à vos besoins, utilisez une unité de style globale d’espacement dans vos propres styles CSS.
