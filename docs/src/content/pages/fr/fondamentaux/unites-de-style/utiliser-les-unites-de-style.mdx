# Utiliser les unités de style

Les composants de Système de design GC utilisent déjà les unités de style. Vous n’avez donc pas besoin de les appliquer vous-même lorsque vous utilisez nos composants.

## Déterminer si vous avez besoin des unités

### Dans le code

Commencez par les <gcds-link href={links.fr.shortcuts}>raccourcis CSS</gcds-link>. Utilisez directement les unités de style dans votre CSS seulement si aucun raccourci CSS ne permet d’appliquer le style dont vous avez besoin.

### Dans Figma

Utilisez les unités de style lorsque vous devez créer des styles personnalisés en dehors des composants de Système de design GC.

## Choisir une unité de style

Choisissez le type d’unité de style qui convient à vos besoins :

- **Utilisez les unités globales** qui correspondent aux styles dont vous avez besoin. Lorsqu’une unité globale est sémantique, choisissez-la en fonction de son utilisation prévue. Référez-vous à la <gcds-link href={links.fr.tokenNaming}>structure du nom</gcds-link> de l’unité de style pour le savoir.
- **Utilisez les unités de base** lorsqu’aucune unité globale ne correspond au style dont vous avez besoin. Les unités de base existent uniquement pour la couleur et offrent un plus grand choix de couleurs.
- **Évitez d’utiliser les unités de composant**, car elles sont propres aux composants de Système de design GC. Les utiliser en dehors du composant auquel elles sont associées peut entraîner des changements inattendus lorsque nous mettons ce composant à jour.

Explorez nos fondamentaux pour choisir l’unité de style qui répond à vos besoins.

## Appliquer les unités de style

### Dans le code

Les unités de style sont disponibles sous forme de propriétés CSS personnalisées dans notre <gcds-link href={links.fr.githubTokens} external>référentiel d’unités de style</gcds-link>.

Dans vos fichiers CSS, utilisez `var()` pour faire référence à une unité de style comme valeur de la propriété que vous définissez, comme dans cet exemple :

```CSS
font: var(--gcds-font-text);
color: var(--gcds-text-primary);
background-color: var(--gcds-bg-white);
```

### Dans Figma

Les unités de style sont disponibles sous forme de variables Figma dans notre <gcds-link href={links.fr.figmaTokens} external>bibliothèque d’unités de style</gcds-link>.

Importez la bibliothèque d’unités de style (« GCDS Token library ») dans votre fichier. Ensuite, dans le panneau Design de Figma, choisissez une variable ou un style de la bibliothèque pour la propriété que vous souhaitez modifier. Par exemple, choisissez une couleur dans **Remplissage** ou un style de texte dans **Typographie**.
