# Extensions

Les extensions sont des ressources qui permettent d’enrichir ou d’adapter Système de design GC pour répondre à des besoins précis.  

**Ces extensions sont maintenues par des équipes autres que celle de Système de design GC**. Communiquez avec ces équipes pour obtenir de l’aide concernant l’accessibilité, la compatibilité ou le soutien.
