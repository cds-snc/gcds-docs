# Raccourcis CSS

Chaque produit numérique a besoin de styles personnalisés. Nous avons fait le travail pour vous.

Les Raccourcis CSS sont un cadre utilitaire CSS conçu pour respecter les styles de Système de design GC et les normes de Canada.ca. Ils fournissent des classes utilitaires CSS prédéfinies qui permettent d’appliquer les éléments fondamentaux du design, comme les <gcds-link href={links.fr.colour}>couleurs</gcds-link>, l’<gcds-link href={links.fr.spacing}>espacement</gcds-link> et la <gcds-link href={links.fr.typography}>typographie</gcds-link>, à votre HTML.

## Raccourcis CSS et unités de style

Les <gcds-link href={links.fr.designTokens}>unités de style</gcds-link> et les raccourcis CSS sont tous deux liés aux styles de Système de design GC, mais ils remplissent des fonctions différentes.

Les unités de style stockent des décisions de style réutilisables. Les raccourcis CSS sont des classes utilitaires prédéfinies qui permettent d’appliquer des styles courants. Certains raccourcis CSS utilisent des unités de style pour leurs valeurs, ce qui leur permet d’être mis à jour automatiquement si la valeur d’une unité change.

Par exemple, le raccourci CSS `mb-500` utilise l’unité de style `--gcds-spacing-500` pour définir la marge inférieure.

## Quand utiliser les raccourcis CSS

Utilisez les raccourcis CSS lorsque vous devez appliquer des styles qui ne sont pas couverts par les composants de Système de design GC.

Utilisez plutôt les <gcds-link href={links.fr.usingTokens}>unités de style</gcds-link> lorsqu’aucun raccourci CSS ne permet d’appliquer le style dont vous avez besoin.

## Comment utiliser les Raccourcis CSS

1. <a href={links.fr.startToUseDevelop}>Sélectionnez le cadre qui s'applique à votre projet</a> et suivez les étapes pour ajouter la feuille de style Raccourcis CSS. Si vous avez déjà installé des composants Système de design GC, passez aux instructions concernant les Raccourcis CSS.
2. Explorez les différentes options de style dans le menu.
3. Ajoutez les classes au code HTML correspondant pour ajuster le style selon vos besoins.

## Avantages

### Cohérence des styles

Les raccourcis CSS utilisent les mêmes unités de style que nos composants. Vos styles personnalisés sont donc cohérents avec les autres ressources de Système de design GC.

### Développement plus rapide, moins de maintenance

Travaillez avec du code plus simple, plus clair et plus facile à entretenir. C'est nous qui gérons les mises à jour, pas vous.

### Aucune dépendance sur des infrastructures tierces

Les Raccourcis CSS sont conçus pour répondre aux besoins du gouvernement du Canada. Contrairement à d'autres cadres utilitaires courants, comme Bootstrap ou Tailwind, nous avons entièrement le contrôle des Raccourcis CSS.

### Accessible à la base

Ajoutez du code personnalisé pour répondre à vos besoins spécifiques, tout en sachant qu'il a été conçu pour répondre aux <a href={links.fr.accessibility}>normes d'accessibilité du GC</a>.
