# Hauteur de ligne

La classe hauteur de ligne définit la propriété `line-height`. Elle détermine l'espacement vertical entre les lignes de texte.

<Notice title="Utiliser avec prudence" html={`Dans la plupart des cas, il n’est pas nécessaire d'utiliser cette classe. Par défaut, le style du corps du texte et des éléments de titre correspondent <gcds-link href="/fr/styles/typographie">à ceux de Système de design GC</gcds-link>. Utilisez des balises HTML sémantiques, comme <code>h1</code> et <code>h2</code> lorsque possible..`} />
