# Taille de lien

La classe taille de lien définit la propriété `font`. Elle détermine la taille d'un lien.

<Notice title="Utiliser avec prudence" html={`Dans la plupart des cas, il n’est pas nécessaire d'utiliser cette classe. Par défaut, le style des liens correspond <gcds-link href="/fr/composants/lien">à celui de Système de design GC (SGDC)</gcds-link>. Utilisez la balise HTML sémantique <code>a</code> ou le composant SGDC <code>gcds-link</code> lorsque possible.`} />
