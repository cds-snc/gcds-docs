# Marge intérieure

La classe marge intérieure définit la propriété `padding`. Elle détermine l’espace à l’intérieur d’un élément, entre le contenu et la bordure.

<LogicalPropertiesNote />

<ShortcutsTable shortcuts={shortcuts} description={tableDescription} />

## Exemples

### Tous les côtés<br />`p-<value>`

<CodePreview demoClass="d-inline-block bg-primary text-light">
  <p class="p-0">Cet élément n’a aucune marge intérieure sur tous les côtés.</p>
</CodePreview>

### Côté supérieur<br />`pt-<value>`

<CodePreview demoClass="d-inline-block bg-primary text-light">
  <p class="pt-300">
    Cet élément a une marge intérieure de --gcds-spacing-300 sur le côté
    supérieur.
  </p>
</CodePreview>

### Côté inférieur<br />`pb-<value>`

<CodePreview demoClass="d-inline-block bg-primary text-light">
  <p class="pb-300">
    Cet élément a une marge intérieure de --gcds-spacing-300 sur le côté
    inférieur.
  </p>
</CodePreview>

### Côté gauche<br />`ps-<value>`

<CodePreview demoClass="d-inline-block bg-primary text-light">
  <p class="p-300 ps-0">

### Côté droit<br />`pe-<value>`
