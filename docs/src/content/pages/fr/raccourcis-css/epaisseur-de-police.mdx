# Épaisseur de police

La classe poids de police définit la propriété `font-weight`. Elle détermine à quel point le texte est en gras.

<Notice title="Utiliser avec prudence" html={`<gcds-link href="/fr/styles/typographie#epaisseurs-de-police">Consulter les directives typographiques de Système de design GC</gcds-link> pour choisir le bon poids de police pour votre contexte.`} />

<ShortcutsTable shortcuts={shortcuts} />

## Exemples

### Normal<br />`font-regular`

<CodePreview>
<p class="font-regular"> Cet élément utilise le poids de police par défaut. </p>
</CodePreview>

### Léger<br />`font-light`

<CodePreview>
<p class="font-light"> Cet élément utilise un poids de police léger. </p>
</CodePreview>

### Moyen<br />`font-medium`

<CodePreview>
<p class="font-medium"> Cet élément utilise un poids de police moyen. </p>
</CodePreview>

### Semi-gras<br />`font-semibold`

<CodePreview>
<p class="font-semibold"> Cet élément utilise un poids de police semi-gras. </p>
</CodePreview>

### Gras<br />`font-bold`

<CodePreview>
<p>Cet élément utilise un poids de police <span class="font-bold"> gras</span>.</p>
</CodePreview>
