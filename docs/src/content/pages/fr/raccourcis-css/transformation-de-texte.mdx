# Transformation de texte

La classe transformation de texte définit la propriété `text-transform`. Elle détermine l’emploi de la majuscule dans le texte.

<ShortcutsTable shortcuts={shortcuts} />

## Exemples

### Mode titre<br />`text-capitalize`

<CodePreview>
<p class="text-capitalize"> Ce texte porte la majuscule initiale sur chaque mot. </p>
</CodePreview>

### Minuscule<br />`text-lowercase`

<CodePreview>
<p class="text-lowercase"> Ce texte est entièrement en minuscules. </p>
</CodePreview>

### Majuscule<br />`text-uppercase`

<CodePreview>
<p class="text-uppercase"> Ce texte est entièrement en majuscules. </p>
</CodePreview>

### Aucune<br />`text-none`

<CodePreview>
<p class="text-none"> Ce texte s’affiche tel qu’il a été saisi à l’origine. Toute transformation de texte est supprimée. </p>
</CodePreview>

<ResponsiveNote partialClass="text-capitalize" />
