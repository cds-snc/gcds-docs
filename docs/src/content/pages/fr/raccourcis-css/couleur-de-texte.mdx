# Couleur de texte

La classe couleur de texte définit la propriété `color`. Elle détermine la couleur du texte.

<Notice title="Utiliser avec prudence" html={`<gcds-link href="/fr/styles/couleur#texte">Voir les conseils de Système de design GC en matière de couleur</gcds-link> pour choisir la bonne couleur de texte pour votre contexte.`} />

<ShortcutsTable shortcuts={shortcuts} />

## Exemples

### Principal<br />`text-primary`

<CodePreview>
<p class="text-primary"> Ce texte utilise la couleur de texte par défaut du gouvernement du Canada. </p>
</CodePreview>

### Secondaire<br />`text-secondary`

<CodePreview>
<p class="text-secondary"> Ce texte utilise la couleur de texte secondaire. </p>
</CodePreview>

### Couleur actuelle<br />`text-current`

<CodePreview demoClass="p-150">
<div class="bg-primary text-light"> <p class="text-current"> La couleur de ce texte est basée sur la propriété de couleur actuelle. </p> </div>
</CodePreview>

### Clair<br />`text-light`

<CodePreview demoClass="bg-dark p-150">
<p class="text-light"> Voici la couleur de texte claire. </p>
</CodePreview>

### Transparent<br />`text-transparent`

<CodePreview>
<p class="text-transparent"> Ce texte est invisible, mais reste accessible aux lecteurs d'écran. </p>
</CodePreview>
