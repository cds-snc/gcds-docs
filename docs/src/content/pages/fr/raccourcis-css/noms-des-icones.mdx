# Noms des icônes

La classe icône définit la propriété `content` et d'autres styles de base d'icône tels que la famille de polices d'icônes, le style et l'épaisseur. Elle détermine l'icône <gcds-link href="/fr/composants/icone">gcds-icon</gcds-link> à afficher.
