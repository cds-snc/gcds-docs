# Couleur de l’arrière-plan

La classe couleur d’arrière-plan définit la propriété `background-color`. Elle détermine la couleur de l’arrière-plan d’un élément.

<Notice title="Utiliser avec prudence" html={`<gcds-link href="/fr/styles/couleur#arriereplan">Voir les conseils de Système de design GC en matière de couleur</gcds-link> pour choisir la bonne couleur d’arrière-plan pour votre contexte.`} />
