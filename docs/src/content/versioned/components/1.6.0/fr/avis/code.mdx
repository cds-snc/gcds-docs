## Codage et accessibilité de l'avis

### Définir le rôle de l'avis

Utilisez l'attribut `notice-role` pour classer l'avis dans les catégories `info` (Information), `warning` (Avertissement), `danger` (Danger) ou `success` (Succès). Ce choix détermine le style visuel de l'avis et communique l'urgence ou l'importance du message au public.

### Précisez le titre et le niveau de l'en-tête de l'avis

- Utilisez l'attribut `notice-title` pour créer un titre clair et informatif pour l'avis. Veillez à ce que le titre transmette l'objectif du message.
- Utilisez `notice-title-tag` pour définir <gcds-link href={`${links.fr.heading}/design#classez-les-niveaux-de-titre-de-maniere-hierarchique`}>le bon niveau</gcds-link> de titre pour l'avis. La définition du niveau adapté pour le titre n'a pas d'incidence sur la taille de la police, mais elle permet de maintenir la bonne hiérarchie et l'accessibilité pour les technologies d'assistance.

<h3 id="section-essential">Attributs essentiels</h3>

Ces attributs sont requis pour que le composant fonctionne correctement.

#### `notice-role`

L'attribut `notice-role` définit le style d'avis à afficher.

<CodePreview iframe>
  <gcds-notice notice-role="success" notice-title="Titre de l'avis succès" notice-title-tag="h2">
    <gcds-text margin-bottom="0">
      Il s'agit d'un message de succès.
    </gcds-text>
  </gcds-notice>
</CodePreview>

#### `notice-title`

L'attribut `notice-title` définit le titre de l'avis.

<CodePreview iframe>
  <gcds-notice notice-role="success" notice-title="Titre de l'avis succès" notice-title-tag="h2">
    <gcds-text margin-bottom="0">
      Il s'agit d'un message de succès.
    </gcds-text>
  </gcds-notice>
</CodePreview>

#### `notice-title-tag`

L'attribut `notice-title-tag` définit l'élément de titre HTML pour le titre. Cette propriété ne modifie pas la taille de la police. Utilisez-la pour assigner le niveau de titre approprié et maintenir la hiérarchie des titres et l'accessibilité.

<CodePreview iframe>
  <gcds-notice notice-role="success" notice-title="Titre de l'avis succès" notice-title-tag="h2">
    <gcds-text margin-bottom="0">
      Il s'agit d'un message de succès.
    </gcds-text>
  </gcds-notice>
</CodePreview>

<h3 id="section-slot">Emplacements (slots)</h3>

L’emplacement par défaut vous permet d’injecter du contenu personnalisé dans la zone de contenu principale du composant, et les emplacements nommés, dans des zones spécifiques.

#### `default`

L'emplacement par défaut sert à placer le message de l'avis.

<CodePreview iframe>
  <gcds-notice notice-role="success" notice-title="Titre de l'avis succès" notice-title-tag="h2">
    <gcds-text margin-bottom="0">
      Il s'agit d'un message de succès.
    </gcds-text>
  </gcds-notice>
</CodePreview>

### Générateur de code

Générez une version du composant dont vous avez besoin en sélectionnant les propriétés de code correspondantes ou explorez les possibilités en choisissant différentes valeurs de code.

1. Choisissez des valeurs de code pour obtenir l'élément que vous voulez.
2. Obtenez le code et intégrez-le dans votre environnement.
3. Ajoutez tout contenu nécessaire au composant (comme le texte du libellé).

**Remarque** : Conformément à la pratique courante, le générateur de code utilise l'anglais pour tous les éléments de code.
